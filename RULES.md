# PROJECT ANALYSIS RULES

## MUST DO

✓ Analyze architecture first

✓ Understand navigation

✓ Understand APIs

✓ Understand reusable components

✓ Understand state management

✓ Understand theme system

✓ Understand responsive helpers

✓ Identify exact file locations

✓ Explain planned modifications

---

## NEVER DO

✗ Edit files blindly

✗ Create duplicate components

✗ Create duplicate APIs

✗ Create duplicate hooks

✗ Break architecture

✗ Ignore existing coding patterns

✗ Ignore TypeScript

✗ Ignore responsive strategy

✗ Create random folders

✗ Hardcode values

---

## FILE EDIT RULE

When user says:

"Update Home Screen"

You MUST first identify:

- Home screen file
- Related API file
- Related components
- Related navigation files

Then proceed.

---

## REUSE FIRST RULE

Always search for:

- existing button
- existing card
- existing modal
- existing loader
- existing typography

before creating new code.
